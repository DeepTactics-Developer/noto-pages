개인정보 처리방침

시행일: 2026년 10월 9일 · 최종 개정: 2026년 10월 12일(앱 버전 1.1.0부터 적용) · 딥택틱스(DeepTactics, 이하 "회사")가 제공하는 iPad 앱 "Noto"에 적용됩니다.

1. 요약

Noto는 개인정보를 수집하지 않습니다. 회사는 서버를 운영하지 않고, 분석 도구나 광고를 쓰지 않으며, 사용자가 앱에서 만든 문서와 필기를 받거나 볼 수 없습니다.

다만 사용자가 설정에서 직접 외부 AI(ChatGPT, Claude, Gemini)를 연결하거나 외부 AI 창을 여는 경우, 사용자가 AI에게 묻는 내용은 그 AI를 제공하는 회사로 전달됩니다. 이 내용도 회사(딥택틱스)는 받거나 볼 수 없습니다. 자세한 내용은 2항과 5항을 확인해 주세요.

2. 앱이 다루는 정보와 저장 위치

  • 문서, 필기, 텍스트, 이미지, 녹음, 플래시카드, 퀴즈, 학습 기록: 사용자의 기기 안에 저장됩니다. 사용자가 설정에서 iCloud 동기화나 iCloud 백업을 켠 경우에 한해 사용자 본인의 iCloud 공간에도 저장되며, 이 내용은 Apple의 iCloud 서비스에서 처리되고 회사는 접근할 수 없습니다.
  • 글자 인식 결과와 기본 AI 처리: 스캔한 글자 인식, 손글씨 인식, 음성 인식, 그리고 기본으로 쓰이는 Apple의 기기 내 AI(Apple Intelligence)의 요약과 질문 답변은 모두 기기 안에서 처리됩니다. 이 경우 문서나 음성이 회사나 제3자의 서버로 전송되지 않습니다.
  • 외부 AI 연결(선택 기능): 사용자가 설정 > AI 엔진에서 본인의 API 키를 입력하고 전송에 동의한 경우에만 사용됩니다. 이때 사용자가 AI에게 묻는 질문과 그에 필요한 문서 내용(질문과 관련된 쪽의 글, 올가미로 고른 내용 등)이 앱에서 해당 AI 회사(OpenAI, Anthropic, Google)의 서버로 직접 전송됩니다. 회사(딥택틱스)의 서버를 거치지 않으며 회사는 그 내용을 받거나 볼 수 없습니다. API 키는 사용자 기기의 키체인에만 저장되고 iCloud 동기화나 백업에 포함되지 않으며, 설정에서 언제든 지우거나 기기 내 AI로 되돌릴 수 있습니다. 전송된 내용에는 해당 회사의 이용약관과 개인정보 처리방침이 적용되고, 사용 요금도 그 회사가 키 주인에게 청구합니다.
  • 외부 AI 창: 툴바의 외부 AI 버튼은 ChatGPT, Claude, Gemini의 웹사이트를 앱 안의 창으로 열어 줍니다. 로그인과 대화 내용은 해당 사이트가 처리하며, Noto는 그 입력과 대화를 읽거나 저장하거나 전송하지 않습니다. 사이트가 남기는 로그인 정보(쿠키)는 이 앱의 웹 보관 영역에 저장되며 앱을 삭제하면 함께 삭제됩니다.
  • 무료 요금제 사용량(글자 인식 쪽수, 문서별 AI 사용 횟수 등): 한도를 계산하기 위해 기기 안에만 저장됩니다.

3. 앱이 요청하는 권한

  • 마이크: 필기와 함께 강의를 녹음할 때만 사용합니다.
  • 음성 인식: 녹음을 글자로 바꾸거나 AI에게 음성으로 질문할 때 사용하며, 기기 안에서만 처리합니다.
  • 알림: 사용자가 설정에서 켠 경우 복습할 카드가 있을 때 기기에서 알림을 예약합니다.
  • 사진, 파일: 사용자가 직접 선택한 PDF와 이미지만 가져옵니다.

권한은 iPad 설정에서 언제든 끌 수 있습니다.

4. 결제

Pro 구매는 Apple의 App Store가 처리합니다. 회사는 이름, 결제 수단, 연락처 등 결제 정보를 받지 않으며, 구매 여부(Pro 권한)만 앱이 확인합니다. 결제와 환불은 Apple의 약관과 정책을 따릅니다.

5. 제3자 제공과 국외 이전

회사는 수집하는 개인정보가 없으므로 제3자에게 제공하거나 위탁하거나 국외로 이전하는 정보가 없습니다. iCloud를 사용하는 경우 Apple의 개인정보 처리방침이 적용됩니다.

사용자가 직접 켠 외부 AI(2항)는 회사가 제공하거나 위탁하는 것이 아니라, 사용자가 본인의 키와 계정으로 해당 회사의 서비스를 이용하는 것입니다. 이때 내용은 사용자의 기기에서 해당 회사(OpenAI, Anthropic, Google)의 서버로 직접 전송되며, 서버가 해외에 있을 수 있습니다. 사용자는 설정에서 외부 AI를 켜기 전에 이를 안내받고 동의하며, 동의하지 않으면 기기 내 AI만 사용됩니다.

6. 보관과 삭제

데이터는 사용자의 기기에 있으므로 앱을 삭제하면 기기의 데이터가 함께 삭제됩니다. iCloud에 저장한 데이터는 iCloud 설정의 저장 공간 관리에서 삭제할 수 있습니다. 앱 안에서도 문서를 삭제하면 휴지통을 거쳐 30일 뒤 영구 삭제됩니다.

7. 아동

Noto는 아동의 개인정보를 수집하지 않으며, 모든 연령이 사용할 수 있는 학습 도구입니다.

8. 이용자의 권리

회사가 보유한 개인정보가 없으므로 열람, 정정, 삭제를 요청할 정보가 없습니다. 앱 안의 모든 데이터는 사용자가 직접 보고, 내보내고, 삭제할 수 있습니다.

9. 방침의 변경

수집하는 정보나 처리 방식이 바뀌면 앱을 업데이트하기 전에 이 문서를 고치고 시행일을 갱신합니다. 이용자에게 불리한 변경은 앱 안 또는 이 페이지에서 미리 알립니다.
